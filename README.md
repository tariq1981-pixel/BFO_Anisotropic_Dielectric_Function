# Anisotropic Dielectric Function of BiFeO₃

This repository contains anisotropic real-part dielectric function
(ε₁) data of pure and doped BiFeO₃ (La-, Co-, and LaCo-doped) obtained
from first-principles numerical simulations.

## Data Description
- Quantity: Real part of dielectric function ε₁(ω)
- Materials: Pure, La-doped, Co-doped, LaCo co-doped BiFeO₃
- Orientations: [100], [110], [111]
- Nature: Simulation-based (first-principles)
- Units: Dimensionless

## Purpose
The data support studies on crystallographic dielectric anisotropy,
optical response, and neuromorphic device modeling.

## Disclaimer
This repository contains no experimental measurements. All datasets
are numerical and benchmarked against values reported in the literature.
